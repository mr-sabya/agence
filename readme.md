# 🏢 Web surface Agency – Django Website

A professional digital agency website built with **Django**, featuring a stylish **Jazzmin-powered admin panel** and a fully dynamic **frontend**.  
This project demonstrates a complete CMS-style agency website where every section — from banner to team members — is editable via the Django admin.

## ✨ Overview

**Web surface Agency** is a modern Django-based web application designed for digital and creative agencies.  
It provides both a sleek frontend website and a feature-rich admin interface for content management.

---

## 🚀 Features

### 🖥️ Frontend Highlights
- Fully responsive design (Bootstrap 5)
- Dynamic homepage with sections:
  - Hero banner  
  - About section  
  - Services and goals  
  - Portfolio showcase  
  - Team members  
  - Testimonials  
  - Blog and news updates  
  - Contact form  
- SEO-friendly and clean design.

### 🔐 Admin Panel (Powered by Jazzmin)
- Modern, clean, and easy-to-navigate UI.
- Manage all content dynamically:
  - Authentication (Users, Groups)
  - Blog (Categories, Tags, Posts)
  - Portfolio (Clients, Projects, Technologies)
  - Website Sections (About, Banner, Services, Team, Testimonials)
- Recent actions and audit logs.
- Role-based access control for administrators.

---

## 🛠️ Technology Stack

| Layer | Technology |
|-------|-------------|
| **Backend** | Django 5+ |
| **Frontend** | HTML5, CSS3, Bootstrap |
| **Database** | SQLite (configurable to PostgreSQL/MySQL) |
| **Admin UI** | Jazzmin |
| **Media Handling** | Django Media Uploads (Pillow) |
